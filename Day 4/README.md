# Salesforce Interview Readiness Bootcamp - Day 4

## Topic
Lightning Web Components (LWC)

## Objective
Build the first Lightning Web Component (LWC) for the Placement Management System and understand the basic structure of an LWC.

## Component Created
**Component Name:** placementHome

## Features Implemented
- Created the first Lightning Web Component.
- Displayed a welcome message.
- Displayed Student Name, Roll Number, and Department.
- Implemented data binding using JavaScript variables.
- Added a button to display a welcome message.
- Changed application status from **Not Applied** to **Applied** using JavaScript.
- Created a simple Placement Portal dashboard displaying:
  - Today's Date
  - Welcome Student
  - Number of Companies
  - Number of Jobs
  - Applications Submitted

## Files Used
- placementHome.html
- placementHome.js
- placementHome.js-meta.xml

## What I Learned
- Introduction to Lightning Web Components (LWC)
- LWC folder structure
- HTML template in LWC
- JavaScript variables and methods
- Data Binding
- Event Handling
- Lightning Button component
- Deploying an LWC to Salesforce
- Adding an LWC to a Lightning Home Page

## Output
The component successfully displays:
- Welcome to Vishnu Placement Portal
- Student Information
- Placement Statistics
- Welcome Message Button
- Application Status Update

## Technologies Used
- Salesforce
- Lightning Web Components (LWC)
- HTML
- JavaScript
- XML

## Conclusion
Successfully created and deployed my first Lightning Web Component and learned the basics of building interactive user interfaces in Salesforce.
